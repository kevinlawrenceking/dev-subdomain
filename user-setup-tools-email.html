TAO UPDATE

Hi Team,

I've created a set of tools that make it easy to ensure users are properly set up. Here's a quick rundown of each one.

1 Log In as a Different User

If there's an issue with a user, Julia or any admin can log in and "impersonate" that user to see exactly what they're seeing — no password needed.

  • Go to the Details screen of the user you want to log in as.
  • Click "Log in as User."
  • While you're logged in, you'll see a red bar at the bottom of the screen. Click it any time to return to your admin account.
2 User Setup Verification Report

A report now runs every day to make sure users are set up correctly. It checks that every user table is populated and automatically fixes any that are missing.

This already fixed Paul Shearman and Skylea Jones.

We've also added more options to our pick lists, which ensures those updates roll out to every user table as well.

3 Create a Test User

You can now create a test user to check the setup from end to end. (Available in DEV now; we'll test in PROD tomorrow.)

  • Click the button and a pop-up will appear.
  • Just add a fake name, and it will create a test user record.
  • The test user has a dummy email, but you'll still receive the email notification with the setup link.

This lets you see the entire setup experience, from email to finish.

4 Setup Steps Modified

We removed the import options and made a few other changes to streamline the setup steps.
