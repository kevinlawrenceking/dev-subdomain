## How to Upload

For each project:
1. Open claude.ai and create (or open) the project
2. Copy the content of `00-PROJECT-INSTRUCTIONS.md` into the project's **Custom Instructions** field
3. Upload all other files (01-xx through the last numbered file) to the project's **Knowledge** section
4. The numbered prefix ensures files display in a logical reading order
