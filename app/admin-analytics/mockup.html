How these numbers are counted

Auditions logged. We link the audition project and audition role records (one-to-one) and count those. We deliberately do not count from the auditions (events) table, because one role can produce several event entries -- the first audition, a callback, a redirect -- so counting events would multiply one real opportunity into many. Counting at the role level gives one clean count per audition.

Bookings logged. The same set of audition records, narrowed to the ones that actually booked -- including a "direct booking" where the actor was booked without auditioning. Bookings is always a subset of auditions.

Relationships added. New people added to the system -- the contacts that make up an actor's network -- based on each contact's creation date, excluding the actor's own profile record. Measures network growth, not follow-up enrollment.

Reminders completed. Reminders marked done, using the date completed (not the date due). Reflects real activity finished.

Time window and charts. Every number reflects the selected range; the charts show the same totals month by month. All figures are system-wide across every user.
